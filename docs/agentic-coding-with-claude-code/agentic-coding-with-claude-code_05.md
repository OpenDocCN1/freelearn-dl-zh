# 第二部分：扩展 Claude Code：协议、自动化与结构化工作流

在本书的*第 2 部分*中，重点从个人使用转向结构化扩展和自动化。你将了解 Claude Code 如何通过**模型上下文协议 (MCP)** 连接到外部工具和服务，以及这些集成是如何被负责任地配置和管理的。我们将通过 GitHub 工作流和事件驱动执行来探讨自动化在实践中是如何运作的。

随着系统变得更加复杂，结构变得至关重要。你将探索基于规划的开发、协调的多代理工作流，以及用于隔离上下文以实现更安全执行的子代理。你还将了解输出样式和配置模式如何塑造行为并强制一致性。在本部分结束时，你将能够设计出深思熟虑、受控且可扩展的工作流。

本部分包含以下章节：

*   *第 4 章*，《使用 MCP 服务器和插件扩展 Claude Code》
*   *第 5 章*，《使用 Claude Code 和 GitHub 自动化你的开发工作流》
*   *第 6 章*，《Claude Code 规划与多代理工作流》
*   *第 7 章*，《使用 Claude Code 子代理》
*   *第 8 章*，《创建和自定义输出样式》
