# 第三部分：高级智能体与深度系统设计

在本书的最后一部分，你将探讨现代编码智能体如何大规模且长周期地运行。我们将探索智能体技能，如结构化能力扩展，并分析它们如何影响上下文流和执行模式。你将看到 `Claude Code` 如何跨环境运行、协调并行开发工作，并支持更高级的编排策略。

我们还将深入系统设计。你将探讨什么使智能体具备“深度”，如何维持长时间运行的执行，以及 `LangChain` 深度智能体等编排框架的内部结构。读完这部分，你将对高级智能体系统的工程实现有实践性和架构层面的理解。

本部分包含以下章节：

* 第 9 章，*理解智能体技能*
* 第 10 章，*使用 Claude Code Desktop*
* 第 11 章，*理解深度智能体*
